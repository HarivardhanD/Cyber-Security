# SOAR

- SOAR --> `SECURITY ORCHESTRATION , AUTOMATION AND RESPONSE`

- Traditionally analyst were needed to swithc between EDR , Firewalls , SIEM but with `SOAR` all of this is available on a single interface

- SOAR : 
    - Connects all your security tools
    - Automates repetitive investigation steps
    - Helps you respond to incidents faster

- SOAR HAS 3 MAIN CAPABILITIES :
    - `ORCHESTRATION` --> INTEGRATING SIEM, EDR , FIREWALL ETC ALL ON A SINGLE INTERFACE , SO DONT HAVE TO CONSTANTLY SWITCH
    - `AUTOMATION` --> IT HAS PLAYBOOKS WITH PREDIFINED RULES AND EXECUTE THE STEPS/CONDITIONS FROM PLAYBOOKS WITHOUT HUMAN NEED
    - `RESPONSE` --> IT RESPONDS TO THE ERROR/ALERT BY ITSELF SENDING COMMANDS TO THE TOOLS
