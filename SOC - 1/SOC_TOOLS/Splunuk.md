# SPLUNK - BASICS

- Splunk is the best solution for SIEM ( securtiy information and event management )

- Splunk has 3 main components :
    - `FORWARDER` --> `Splunk forwarder` are on the endpoints and then its task is to collect data and sent to the` splunk  instance`
    - `INDEXER` --> `splunk INDEXER` Normalizes and converts the data into key-value pairs and stores it .
    - `SEARCH HEAD` --> `Splunk Search Head` is the place within the `Search & Reporting App` where users can search the indexed logs.Searches are done use `SPL -- SEARCH PROCESSING LANGUAGE`
