# Humans as Attack Vectors

- How attackers `target` --> `weakest cybersecurity` element --> `HUMANS`

- Computer network is a fort and humans are gatekeepers
    - Either break through fort
    - OR
    - Ask the gatekeepers the key to enter it 
    
- For `HUMANS` attacker use a `Social Engineering`( psychological tactic )

- `Trustworthy`: The attacker must appear legitimate so the victim trusts them
- `Emotional`: The attack must trigger feelings like urgency, fear, or curiosity

- PHISHING ATTACKS :
    - Using fake emails with malware attachments

- MALWARE DOWNLOADS :
    - This can happen via `Browser update`
    - Via `Captcha's` as well

- DEEPFAKES
- IMPERSONATION
- PHYSICAL ATTACKS
- INSIDER THREAT
- USB DROP CAMPAIGNS

### DEFENDING HUMANS

- TWO METHODS FOR DEFENDING THE THREAT :
    - MITIGATION --> usning anti-phishing methods, trainiing employee etc
    - If these are bypassed, then the next method below
    - DETECTION --> BY SOC TEAM\


- `MITIGATIONS` can be as follows :
    - `ANTI-PHISHING SOLUTIONS`
    - `ANTIVIRUS`
    - `TRUST BUT VERIFY PRINCIPLE`
    - `TRAINING EMPLOYEES`
